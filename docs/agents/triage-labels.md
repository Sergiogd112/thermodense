# Triage labels

The skills use five canonical triage roles. Their issue-label mappings in this repository are:

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Work is waiting on information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Human implementation or action is required |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill names a canonical role, apply the corresponding GitHub label from this table.
